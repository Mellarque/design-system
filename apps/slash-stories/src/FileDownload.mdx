## FileDownload

The FileDownload component allows users to download or consult documents with optional status indicators and custom icons.

### Import

```tsx
import { FileDownload } from "@axa-fr/canopee-react/distributeur";
```

### Use

#### Basic Example

<Canvas of={FileDownloadStories.Playground} />

<Controls of={FileDownloadStories.Playground} />

```tsx
export const FileDownloadExample = () => (
  <FileDownload
    label="Mon superbe document"
    fileName="mon-superbe-document.pdf"
    status="En cours"
    onConsult={async () => {
      // handle consult
    }}
    onDownload={async () => {
      // handle download
    }}
  />
);
```

## Variations

Action buttons require a callback to be displayed

## Props

### label (required)

The main title of the document. Always displayed.

### fileName (optional)

The name of the document file. Displayed below the label in smaller text.

### status (optional)

A status badge displayed to the right of the label. Examples: "En cours", "Validé", "Expiré".

### iconSrc (optional)

Custom icon SVG source.

### onConsult (optional)

Callback function triggered when the "Consulter" button is clicked. Must return a Promise.

### onDownload (optional)

Callback function triggered when the "Télécharger" button is clicked. Must return a Promise.
